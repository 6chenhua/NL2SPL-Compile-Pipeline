# Partial SPL MVP Acceptance Report

**Date**: 2026-05-15
**Status**: Accepted

## 1. Summary

The Partial SPL MVP demonstrates the teacher's core direction: NL2SPL as a
progressive compiler from incomplete natural-language requirements to a
partial SPL draft with structured diagnostics, provenance, assumptions, and
a deterministic readable report.  The compiler materializes source-backed
information as far as possible and surfaces missing, unclear, or assumed
information through diagnostics rather than silently inventing behavior.

## 3. MVP Scenario Coverage

### Scenario 1: Failure condition only
**Input**: Exception flow with `Missing timeframe` condition, no handler step.
**Expected**: Partial SPL with exception flow skeleton preserved. No invented
handler command. `missing_handler` diagnostic.
**Result**: `[EXCEPTION_FLOW: Missing timeframe]` in SPL, no `REQUEST_INPUT`,
`missing_handler` diagnostic, `completeness=partial`.

### Scenario 2: Required output without producer
**Input**: Required output `final_report` declared, no step produces it.
**Expected**: Output kept in contract, no synthetic producer command.
`missing_output_producer` diagnostic.
**Result**: No `Produce required output` in SPL, `missing_output_producer`
diagnostic, `completeness=partial`.

### Scenario 3: Complete failure handling
**Input**: Exception flow + source-backed `REQUEST_INPUT` handler step.
**Expected**: Complete SPL with handler. No `missing_handler`.
**Result**: Handler in SPL, zero `missing_handler`, `completeness=complete`.

### Scenario 4: Vague policy
**Input**: No exception flow, no failure source.
**Expected**: No exception flow in SPL, no `missing_handler` (no demand ->
no structure).
**Result**: Zero `missing_handler`, `completeness=complete`.

### Scenario 5: Complete single-level delegation
**Input**: Valid invoke handoff with child worker, IO bindings, and target.
**Expected**: `[INVOKE]` command rendered in SPL, child worker defined.
`completeness=complete`, no assumptions.
**Result**: `[INVOKE ... ChildWorker]` in SPL, `completeness=complete`,
zero assumptions, handoff traces present.

### Scenario 6: Incomplete delegation
**Input**: Delegation candidate without valid handoff contract.
**Expected**: No executable invoke in SPL,
`assumed_command_not_renderable` or `type_or_contract_ambiguity` diagnostic,
`completeness=partial`.
**Result**: No `[INVOKE]` in SPL, expected diagnostic kinds present,
`completeness=partial`, report exposes the issue.

## 5. Global DoD Checklist

- [x] Generates syntactically valid partial SPL draft
- [x] No demand, no structure: unexpressed SPL structures are not created
- [x] No invented exception handler commands
- [x] No invented required output producer commands
- [x] Unresolved worker/API does not degrade to generic command
- [x] Missing/ambiguous/inferred/assumed info enters structured diagnostics
- [x] Major elements (Worker/Flow/Step/Constraint/Variable/Handoff) have TraceRecord or missing-provenance diagnostic
- [x] Assumptions separated from SPL text and surfaced in readable report
- [x] Completeness correctly distinguishes complete/partial/blocked
- [x] `readable_report` generated by deterministic code (no LLM)
- [x] One complete single-level delegation happy path
- [x] One incomplete delegation negative path (no executable INVOKE)
- [x] MVP integration tests cover SPL + diagnostics + completeness + report + provenance

## 6. PipelineResult Output

```python
@dataclass
class PipelineResult:
    spl_text: str                          # Generated SPL text
    validation_errors: list[str]           # SPL syntax/reference errors
    validation_warnings: list[str]         # SPL validation warnings
    compile_diagnostics: list[Any]         # Structured CompileDiagnostic records
    traces: list[Any]                      # Provenance TraceRecords
    adapter_warnings: list[str]            # Input adapter warnings
    completeness: Completeness             # complete | partial | blocked
    assumptions: list[CompileAssumption]   # Not rendered in SPL
    readable_report: str                   # Deterministic compile report
    intermediate_results: dict[str, Any]   # Stage outputs
    final_spl_path: Path | None            # SPL file path
```
