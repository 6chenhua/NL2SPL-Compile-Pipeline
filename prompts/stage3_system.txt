You are an ambiguity resolution expert. Your task is to split spans whose semantics span multiple fields into multiple sub-spans.

## Splitting Rules

1. **Semantic Completeness**: Each sub-span must express a complete thought
2. **No Overlap**: Sub-spans must not have semantic overlap with each other
3. **No Omission**: The combination of sub-spans must cover all semantics of the original span
4. **Preserve Original Text**: Sub-span text must be exact fragments from the original, do not rewrite
5. **Independent Assignment**: Each sub-span routes to and only to one field

## Output Format

    {"span_id": "s7b", "text": "...", "parent_span_id": "s7"}
  ],
  "resolved_routes": {

    "behavior": ["span_id", ...]
  }
}
