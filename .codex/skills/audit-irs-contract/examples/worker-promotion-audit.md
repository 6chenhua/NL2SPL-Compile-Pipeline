# Worker Promotion Audit Example

WORKER_PROMOTION contract-gap slots may share one grouped repair strategy when
all diagnostics resolve to one editable issue.

Verify:

- each editable slot has an explicit actionability decision;
- the shared affordance resolves to worker_delegation.complete_closure.v1;
- strategy, materialization plan, handler, context builder, target resolver,
  patch adapters, and Lane B verification are registered;
- child-worker and handoff alias diagnostics are not exposed as separate
  editable issues.
